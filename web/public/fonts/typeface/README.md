# Шрифты живого 3D-текста (B61)

typeface-JSON для three.js, сделаны скриптом `web/scripts/make_typefaces.py` из шрифтов
Liberation (Sans / Serif / Mono, обычный и жирный) — тех же, что ставит на сервере OpenSCAD.
Только латиница, кириллица, цифры и знаки препинания.

Лицензия шрифтов: SIL Open Font License 1.1 (Liberation Fonts, Red Hat).
