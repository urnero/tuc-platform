Правила для сайта:
- Материалы FDM: любые прутки, **кроме ASA**. SLA: все стандартные смолы — считаются «по запросу» (DECISIONS 2026-10-27).
- Максимальный размер FDM-детали для проверки «влезает»: 256×256×256 (P1S). `PRINT_BED_MM=256x256x256`. Детали больше — предупреждение «печатаем частями или по запросу».
- Многоцветная печать (раскраска по частям, B31) — на P1S и Kobra 3: до 4 цветов за один запуск; больше — предупреждение.
- Материалы, требующие закрытой камеры (ABS, PC, PA, *-CF), — только P1S и Q1 Pro: в `config/materials.yaml` поле `needs_enclosure: true`, max размер для них 256×256×256 (P1S) — Q1 Pro меньше.
- Размеры областей — по паспортам производителей; владелец может уточнить.
- Справочник материалов для сайта — `config/materials.yaml` (B44): поля `needs_enclosure`, `max_mm`, `colors` держать в согласии с этой таблицей.
