Подключение сервисов к сайту BroPrint

Сайт broprint3d.ru уже работает. Чтобы заказы приходили в Telegram, файлы ложились в Google Drive, а оплата проходила онлайн, нужны ключи от этих сервисов. Ключи создаёте вы. Кладёте их в один файл на сервере. Это одна-две сессии по 20 минут.

00

Как всё связано

клиент ──► сайт broprint3d.ru ──► заказ в базе │ ┌──────────────────────┼──────────────────────┐ ▼ ▼ ▼ Telegram-бот Google Drive Google-таблица карточка заказа папка с файлами строка в листе кнопки статусов «Заказы сайта/…» «Заказы (сайт)» │ ▼ клиент получает статус (письмо или Telegram) оплата: сайт ──► ЮKassa ──► вебхук ──► заказ «оплачен»

Каждый сервис включается своей переменной в файле .env. Пока переменная пустая, сервис выключен, сайт работает без него.

01

Файл .env на сервере

5 минутнужно: PowerShell

Все ключи живут в одном файле на сервере: /srv/tuc/prod/.env. У тестового стенда свой файл: /srv/tuc/staging/.env. В чат ключи не присылайте.

  1. Зайдите на сервер. 
    ssh root@141.133.201.70
  2. Откройте файл в редакторе. 
    nano /srv/tuc/prod/.env
  3. Стрелками найдите нужную строку. Впишите значение после знака =. Без пробелов и кавычек.
  4. Сохраните: Ctrl+O, Enter. Выйдите: Ctrl+X.
  5. Перезапустите сайт, чтобы он прочитал новые значения. 
    cd /srv/tuc/prod && docker compose up -d
Эти пять шагов повторяются в каждом разделе ниже. Дальше написано только, какие строки менять.
02

Telegram-бот

10 минутнужно: телефон с Telegramдаёт: заказы в Telegram, статусы клиентам

Что делает бот

Новый заказ приходит вам карточкой: номер, клиент, материал, граммы, часы, сумма, ссылки на файлы и админку. Под карточкой кнопки статусов: «печатается», «готов», «выдан». Нажали кнопку — клиент получил письмо или сообщение. Тот же бот клиент может подключить со страницы заказа, чтобы получать статусы в Telegram.

Шаги

  1. В Telegram откройте @BotFather. Отправьте /newbot.
  2. Имя бота: BroPrint. Username: broprint3d_bot (если занят, добавьте цифру).
  3. BotFather пришлёт токен вида 1234567890:AAH…. Скопируйте его.
  4. Откройте @userinfobot, нажмите Start. Он покажет ваш Id: число из 9–10 цифр. Скопируйте.
  5. На сервере (раздел 01) впишите в .env: 
    TELEGRAM_BOT_TOKEN=1234567890:AAH…
TELEGRAM_OWNER_CHAT_ID=123456789
  6. Перезапустите сайт (шаг 5 раздела 01). Откройте своего бота в Telegram и нажмите Start.

Проверка

cd /srv/tuc/prod && docker compose logs --tail 20 bot

В логе должна быть строка про запуск бота без слова error. Затем оформите тестовый заказ на сайте. Карточка придёт в Telegram в течение 10 секунд.

Бот слушает только ваш chat_id. Брату или сотруднику нужен второй id — пока сайт поддерживает одного получателя. Напишите Claude, если нужны двое.
03

Google Drive и таблица учёта

20 минутнужно: аккаунт Google, PowerShellдаёт: файлы заказов в Drive, строка заказа в таблице

Как это работает

Сайт заходит в Google не под вашим паролем, а под отдельным «сервисным аккаунтом». Это технический пользователь с длинным e-mail. Вы даёте ему доступ к одной папке и одной таблице, как обычному коллеге. Пароль сервисного аккаунта — это JSON-файл. Он лежит на сервере.

А. Создать сервисный аккаунт

  1. Откройте console.cloud.google.com/projectcreate. Название проекта: broprint. Нажмите Create. Подождите минуту.
  2. Включите два API. Откройте Google Sheets API → Enable. Затем Google Drive API → Enable. Вверху должен быть выбран проект broprint.
  3. Откройте Service Accounts → Create service account. Имя: broprint-site. Нажмите Create and continue, затем Done. Роли не нужны.
  4. В списке появится аккаунт с e-mail вида broprint-site@broprint-….iam.gserviceaccount.com. Скопируйте этот e-mail. Он нужен в шагах Б и В.
  5. Нажмите на аккаунт → вкладка Keys → Add key → Create new key → JSON → Create. Браузер скачает файл. Переименуйте его в google-sa.json.

Б. Дать доступ к таблице

  1. Откройте таблицу «Учет 3D-печати ТУЦ».
  2. Кнопка «Настройки доступа» → вставьте e-mail сервисного аккаунта → роль «Редактор» → снимите галочку «Уведомить» → Отправить.
  3. Сайт сам создаст лист «Заказы (сайт)». Ваши листы он не трогает.

В. Папка для файлов заказов

  1. В Google Drive создайте папку Заказы сайта.
  2. Правый клик → «Настройки доступа» → e-mail сервисного аккаунта → «Редактор» → Отправить.
  3. Откройте папку. В адресной строке после folders/ стоит id вида 1AbC…. Скопируйте его.

Г. Положить ключ на сервер

  1. На компьютере откройте PowerShell в папке, где лежит google-sa.json (обычно «Загрузки»). 
    cd $HOME\Downloads
  2. Скопируйте файл на сервер. Спросит пароль root. 
    scp google-sa.json root@141.133.201.70:/srv/tuc/prod/secrets/google-sa.json
  3. Если команда ответила, что папки secrets нет, сначала создайте её на сервере: 
    ssh root@141.133.201.70 "mkdir -p /srv/tuc/prod/secrets && chown deploy:deploy /srv/tuc/prod/secrets"
    Затем повторите шаг 2.
  4. На сервере сделайте файл читаемым только для сайта: 
    chown deploy:deploy /srv/tuc/prod/secrets/google-sa.json && chmod 600 /srv/tuc/prod/secrets/google-sa.json
  5. Удалите файл с компьютера из «Загрузок». Он нужен только на сервере.

Д. Включить в .env

GOOGLE_SA_JSON_PATH=/srv/secrets/google-sa.json
GOOGLE_SHEET_ID=1PmaR0g5iRZx4_p4e1-m0i5ztYChY0BUjfqr_PtL7XbE
GOOGLE_SHEET_TAB=Заказы (сайт)
GOOGLE_DRIVE_FOLDER_ID=<id папки из шага В.3>

Путь /srv/secrets/google-sa.json именно такой: это адрес файла внутри контейнера, а не на сервере. Перезапустите сайт (раздел 01, шаг 5).

Строка GOOGLE_DRIVE_FOLDER_ID появится в .env.example после задачи B46. Если её ещё нет в вашем .env, просто допишите строку в конец файла.

Проверка

cd /srv/tuc/prod && docker compose exec api python -m app.sheets

Команда переписывает лист «Заказы (сайт)». Откройте таблицу: лист появился, в нём заголовки и ваши тестовые заказы. Если ошибка «403» или «permission» — e-mail сервисного аккаунта не добавлен в доступ (шаг Б.2).

04

ЮKassa: оплата картой

15 минут + модерация 1–3 днянужно: ИП или самозанятостьдаёт: кнопка «Оплатить» на сайте
  1. Зарегистрируйтесь на yookassa.ru. Подключите магазин: сайт https://broprint3d.ru, деятельность «3D-печать на заказ».
  2. Пока магазин на модерации, доступен тестовый магазин. Начните с него: платежи не настоящие, можно проверить весь путь.
  3. В кабинете: Интеграция → Ключи API. Скопируйте shopId и создайте секретный ключ. Тестовый начинается с test_, боевой с live_.
  4. Там же: Интеграция → HTTP-уведомления. URL: 
    https://broprint3d.ru/api/v1/payments/yookassa/webhook
    События: payment.succeeded и payment.canceled.
  5. В .env: 
    YOOKASSA_SHOP_ID=123456
YOOKASSA_SECRET_KEY=test_…
YOOKASSA_VAT_CODE=1
    YOOKASSA_VAT_CODE=1 означает «без НДС». Если чеки 54-ФЗ не подключены, оставьте строку пустой.
  6. Перезапустите сайт. Оформите заказ, нажмите «Оплатить». Тестовая карта: 5555 5555 5555 4477, любой срок, любой CVC. Заказ должен стать «оплачен», карточка в Telegram обновится.
  7. После модерации замените ключ на live_… и перезапустите сайт.
05

Почта для писем клиентам

10 минутдаёт: вход в кабинет по коду, письма о статусе

Подойдёт любой почтовый ящик с SMTP. Проще всего Яндекс: ящик orders@broprint3d.ru через Яндекс 360 для бизнеса или обычный …@yandex.ru.

  1. В настройках Яндекс Почты включите «Почтовые программы → по протоколу IMAP/SMTP».
  2. Создайте пароль приложения: id.yandex.ru/security/app-passwords → «Почта». Это не пароль от аккаунта.
  3. В .env: 
    SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SSL=true
SMTP_USER=orders@broprint3d.ru
SMTP_PASSWORD=<пароль приложения>
SMTP_FROM=orders@broprint3d.ru
  4. Перезапустите сайт. Откройте broprint3d.ru/account, введите свой e-mail. Код должен прийти за минуту.
